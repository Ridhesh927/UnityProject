# Unity Projects & Assignments Collection

This repository houses all Unity games, assignments, and experimental projects in a unified monorepo structure.

## Overview

Each subfolder is an independent Unity project containing all necessary `Assets`, `Packages`, and `ProjectSettings`. Temporary and cache folders (`Library/`, `Temp/`, `Logs/`, `obj/`, `.vs/`) are excluded to keep the repository lightweight. When opening any project in the Unity Editor / Unity Hub, Unity will automatically re-generate its `Library` cache.

## How to Open Any Project

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Ridhesh927/UnityProject.git
   ```
2. Open **Unity Hub**.
3. Click **Add project from disk**.
4. Browse to and select any of the subfolders (e.g. `UnityProject/Hostel Damned`).
5. Select the matching Unity Editor version and launch. Unity will regenerate the required `Library/` files automatically.
